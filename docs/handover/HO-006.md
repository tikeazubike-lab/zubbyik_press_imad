## 2. Architecture (3-Tier)

```
Tier 0 — Static Q&A cache (18 patterns)
  │ miss
  ▼
Tier 1 — Knowledge retrieval (keyword-overlap scoring against CPTs)
  │ score < 0.35
  ▼
Tier 2 — LLM fallback (opencode.ai API, mimo-v2.5 model)
```

| Tier | Purpose | Response Time | Cost |
|------|---------|--------------|------|
| Tier 0 | Greetings, skills, projects, experience, pricing, contact | <1ms | Free |
| Tier 1 | CPT-based answers (specific skills, projects, testimonials) | <1ms | Free |
| Tier 2 | Novel questions, opinion, open-ended | ~1-3s | ~$0.0002/conversation |

## 9. Important Gotchas

1. **OPcache** — After editing `inc/ai-chat-bot.php`, run `opcache_reset()` via Docker:
   ```bash
   docker exec malachy-wp php -r 'opcache_reset();'
   ```

2. **Rate limits** — 20 requests per IP per hour via WordPress transients. Clear with:
   ```bash
   docker exec malachy-wp bash -c 'wp db query "DELETE FROM wp_options WHERE option_name LIKE \"%malachy_chat_rl_%\""'
   ```

3. **Context cache** — Cleared automatically when CPTs are saved, or manually:
   ```bash
   docker exec malachy-wp bash -c 'wp transient delete malachy_chat_context && wp transient delete malachy_chat_knowledge_index && wp transient delete malachy_chat_structured_context'
   ```

4. **Exit-intent modal** — Only fires 15s after page load, only if user hasn't scrolled or interacted with the chatbot

5. **Near-miss log** — Inspect with:
   ```bash
   docker exec malachy-wp wp option get malachy_chat_nearmiss_log --format=json
   ```
