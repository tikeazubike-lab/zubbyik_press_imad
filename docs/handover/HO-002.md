## 1. Summary

Integrated an AI chatbot into the Malachy Portfolio WordPress theme. The chatbot uses a **three-stage progressive disclosure** UI (launcher → input bar → panel), calls the **opencode.ai API** (OpenAI-compatible), and handles **12 common questions instantly** via a static Q&A cache without hitting the LLM. When the LLM is unavailable, it offers a **contact form fallback**. The chatbot speaks in **first person** as Malachy.

## 2. Architecture

```
Browser (visitor)
  │
  │ vanilla JS widget (ai-chat-bot.js)
  │
  ├──► Stage 1: Launcher button (fixed bottom-right, pulse glow, sparkle icon)
  │      │ click
  │      ▼
  ├──► Stage 2: Input bar (pill shape, "What would you like to build?")
  │      │ type + Enter / click send
  │      ▼
  ├──► Stage 3: Full conversation panel (380×400px, glassmorphism, messages)
  │      │ click outside / Escape
  │      ▼
  │   Collapse back to launcher
  │
  └──► Exit-intent overlay (only if never interacted)
         │ mouse moves to top edge (clientY < 20)
         ▼
      Full-screen modal with chatbot
         │ click outside / Escape
         ▼
      Back to launcher

Widget JS ──POST /wp-json/malachy/v1/chat──► WordPress REST API (PHP)
                                              │
                                              ├── Static Q&A cache (12 patterns)
                                              │     ↓ if no match
                                              ├── Fetch portfolio context from CPTs
                                              ├── Build messages array for LLM
                                              ├── POST https://opencode.ai/zen/go/v1/chat/completions
                                              │     Model: mimo-v2.5
                                              │     Bearer: OPENCODE_API_KEY
                                              ├── Return { reply: string }
                                              └── If lead detected → POST /wp-json/malachy/v1/chat/lead
                                                     └── wp_mail() to site owner
```

## 4. Static Q&A Cache — All 12 Patterns

The chatbot answers 12 common questions **instantly** (no LLM call) via pattern matching in `get_static_answer()`:

| # | Pattern | Example Inputs | Response Summary |
|---|---------|----------------|------------------|
| 1 | **Greetings** | hi, hello, hey, good morning, yo, sup | "Hello! I'm Malachy — QA Engineer, SysAdmin & developer. How can I help you today?" |
| 2 | **About / Who are you** | who are you, tell me about yourself, what do you do, what is your role, introduce yourself | First-person intro with skills overview |
| 3 | **Skills** | skill, what can you, what do you know, capabilities, expertise, services, technologies, stack | Full categorized list: QA, SysAdmin, Containerization, DevOps, WordPress, LLM |
| 4 | **Portfolio link** | link to your, url of your, website, site address, where can i see, visit your | Returns actual portfolio URL |
| 5 | **Projects** | what have you built, work sample, case study, showcase, tell me about your projects, list your projects | 3 projects: QA Suite, Infra Console, WP Theme |
| 6 | **Experience** | experience, work history, career, job, role, employment | 4 timeline entries: 2017–Now |
| 7 | **Contact / Hire** | hire, contact, available, booking, engagement, work together, reach you, email, get in touch | Lead capture form prompt |
| 8 | **Chatbot / AI** | chatbot, chat bot, ai integration, ai chat, artificial intelligence, llm, ai assistant | AI integration pitch + lead capture |
| 9 | **WordPress** | wordpress, wp, theme, plugin, cms | WP expertise description + lead capture |
| 10 | **Email deliverability** | email deliverability, spam, dkim, spf, dmarc, email authentication | Email skills + lead capture |
| 11 | **Automation** | automate, automation, workflow, ci/cd, pipeline, devops | Automation services + lead capture |
| 12 | **Pricing** | price, cost, rate, how much, pricing, budget, quote | Quote request → lead capture |

**Additional patterns handled:**
- "thanks" / "thank you" → "You're welcome! Is there anything else I can help with?"

**Anything NOT in the cache falls through to the LLM** for a detailed, conversational answer.

## 5. LLM Integration Details

### API Configuration

| Setting | Value |
|---------|-------|
| **Endpoint** | `https://opencode.ai/zen/go/v1/chat/completions` |
| **Model** | `mimo-v2.5` (fast, no reasoning overhead) |
| **Auth** | Bearer token via `OPENCODE_API_KEY` |
| **Max tokens** | 1024 |
| **Temperature** | 0.7 |
| **Timeout** | 30 seconds |

### System Prompt

The system prompt instructs the AI to:
- Speak in **first person** ("I", "my", "me") — never third person
- Use portfolio context to answer factually
- Offer a contact form when it can't showcase specific work
- Describe services based on skills when asked about capabilities
- Keep responses to 2-3 short paragraphs

### Portfolio Context (Cached)

Fetched from WordPress CPTs on startup and cached for 1 hour:
- **Skills** (8 entries) — title, description, level
- **Projects** (3 entries) — title, description, tech stack
- **Experience** (4 entries) — title, company, duration
- **Blog posts** (5 latest) — title, excerpt
- **About** — bio, specialization, availability

Context cache key: `malachy_chat_context` (1 hour TTL)
Cache clears automatically when any CPT is saved.

## 7. Lead Capture Flow

1. Bot detects hiring/contact intent in LLM response (regex patterns)
2. Bot shows inline form with Name + Email fields
3. Visitor fills form and clicks Submit
4. JS sends POST to `/wp-json/malachy/v1/chat/lead`
5. PHP validates, sanitizes, sends `wp_mail()` to site owner
6. Success message shown in chat

**Email recipient:** Configured via Settings → Malachy Portfolio → Contact Form Email (default: `malachy.egbuna@imadconsulting.co.uk`)

**Lead email format:**
```
[Chatbot Lead] New inquiry from {name}

Name: {name}
Email: {email}
IP: {visitor_ip}
Date: {timestamp}

Note / Conversation:
{full chat transcript}
```

## 16. Troubleshooting

| Issue | Cause | Fix |
|-------|-------|-----|
| Chatbot shows "temporarily unavailable" | API key missing or invalid | Check `OPENCODE_API_KEY` in wp-config.php |
| "Too many messages" error | Rate limit hit (10/hour) | Wait 1 hour or clear transients via WP-CLI |
| Markdown not rendering | Old JS cached | Hard refresh (Ctrl+Shift+R) |
| Input field clipped on right | CSS specificity issue | Check `.ai-chatbot-panel-input .ai-chatbot-input-bar` has `width: 100% !important` |
| Scroll shows end of answer | Old scroll logic | Verify `scrollIntoView({ block: 'start' })` in JS |
| Static answers not matching | Pattern too broad/narrow | Check regex patterns in `get_static_answer()` |
| Lead email not sending | wp_mail() blocked by host | Install SMTP plugin (WP Mail SMTP) |
| Widget not appearing | JS error in console | Check `#ai-chatbot-root` exists in footer.php |

## 17. Key Design Decisions

| Decision | Rationale |
|----------|-----------|
| **Static Q&A cache first** | Instant responses for common questions, no LLM latency or cost |
| **mimo-v2.5 model** | Fast, no reasoning overhead (unlike deepseek-v4-flash which burns tokens on thinking) |
| **First person voice** | More natural, conversational — speaks as Malachy directly |
| **Contact form fallback** | When LLM unavailable, visitors can still reach out |
| **No localStorage persistence** | Sessions reset on page refresh — clean slate each visit |
| **New chat button** | Manual reset option in panel header |
| **Exit-intent modal** | Captures visitors about to leave without interacting |
| **Vanilla JS (no React)** | Matches theme philosophy — no build step, no npm |
| **Rate limiting (10/hour)** | Prevents abuse while allowing正常使用 |
