non-hypothetical path for these logs to end up centralized and searchable

log lines is worth closing immediately since the fix is trivial:

```python
# in app/main.py or wherever logging is configured, add:
logging.getLogger("httpx").setLevel(logging.WARNING)
```
This suppresses httpx's default INFO-level request logging (which is what's
printing the full URL including the token) while leaving your own
`imad.*` loggers untouched. Confirm with a test send afterward that the
container log no longer shows the token, and report that confirmation.
