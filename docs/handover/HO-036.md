## 2. §3 — `.shop` confirmation: confirmed dead, not inconsequential-but-harmless

HO-035 read was that `.shop` is "permanently and deliberately retired" and the
cert failures are likely inconsequential. Confirmed, and stronger:

```
$ dig +short zubbystudio.shop                 # (no A record)
$ dig +short estate.zubbystudio.shop          # (no A record)
$ dig +short edu.erpnext.zubbystudio.shop     # (no A record)
$ dig +short NS zubbystudio.shop              # (no NS records at all)
```

The **entire `zubbystudio.shop` zone has no NS records** — it is not just
unused, it is gone from DNS. Nothing can resolve to those hosts, so the
failing cert renewals (`testdrive.epm…`, `showcase…`, `blog…`, `testbuild…`)
cannot break any live routing. The four failing hostnames were individually
checked and none resolve either.

reality; the working domains are all `.site` now. Flagging it as a

noting; can be silenced by raising the `httpx` logger level or filtering, if
wanted. Not fixed here — outside this handover's scope.
