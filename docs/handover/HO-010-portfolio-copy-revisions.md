## About Page

**Heading (revised):**
> Software and servers, sorted.

**Body copy (revised):**

I'm Malachy. Most of what I do comes down to one thing: making sure things work before someone else finds out they don't.

Some days that means writing test suites that catch a bug before it reaches production. Other days it's keeping a Linux server patched, monitored, and boring — in a good way. I've spent enough time on both sides of that line to know they're really the same job: reduce the number of surprises.

Day to day, I work in Playwright, Docker, and Linux. More recently, I've been building with LLMs as part of the actual workflow — writing the spec first, then working with an AI model to build against it, and reviewing what comes out the same way I'd review a pull request from anyone else.
