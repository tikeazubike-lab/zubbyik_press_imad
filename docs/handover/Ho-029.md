## 1. Decision

Malachy has pointed `api.imadconsulting.co.uk` directly at the Netcup VPS
on Cloudflare. **The API hostname is now, permanently,
`api.imadconsulting.co.uk`** — HO-028's `api.imad.zubbystudio.site` is
reverted and no longer in use anywhere.

## 2. Why this is the better outcome, not just a reversal

HO-028 §3 flagged an open risk: using a `zubbystudio.site` subdomain
coupled a live, client-facing revenue feature to Malachy's personal VPS
domain, which has already migrated once for cost reasons. That risk is
now fully closed, not deferred — the API lives under the actual production
domain clients already trust, with no dependency on `zubbystudio.site`'s
history or DNS management going forward. This is the end state HO-028 §3
said would need a conscious decision "before real client traffic depends
on this in production" — it's been made now, correctly, rather than left
open.
