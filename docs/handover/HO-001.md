## Handoff Notes

- **No ACF** — all meta boxes are native WordPress `register_meta` + custom HTML.
- **WP_DEBUG is ON** — the live wp-config has WP_DEBUG enabled. Disable for production.
- **Permalinks** — set to `/%postname%/`, flushed.
- **Front page** — set to "Your latest posts" mode for `front-page.php` rendering.
- **Contact form** — emails go to `admin_email`. Works via `wp_mail()`.
- **GSAP** — standard free license (personal portfolio blog, no commercial sale).
- **Portrait image** — user-provided `human_image.png` → `malachy-portrait.png`.
- **DNS** — `imadconsult.zubbystudio.site` → `185.216.177.250` (Cloudflare proxied).
- **Traefik** — routing via `openagile_openagile_network`.
