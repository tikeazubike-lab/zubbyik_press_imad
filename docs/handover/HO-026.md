### Dual submit

`Promise.allSettled` fires both WordPress AJAX (email via `wp_mail()`) and backend API (Telegram) independently. Either succeeding shows success to the user. If backend fails, email still fires. If WordPress AJAX fails, Telegram still fires. Lead only truly lost if both fail.
