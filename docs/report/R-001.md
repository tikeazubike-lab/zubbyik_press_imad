## 4. AI Chatbot Implementation

### 4.1 Architecture Overview

```
Browser (visitor)
  │
  │ vanilla JS widget (ai-chat-bot.js)
  │
  ├──► Stage 1: Launcher button (52px, bottom-right, pulse glow)
  │      │ click
  │      ▼
  ├──► Stage 2: Input bar (pill shape, "What would you like to build?")
  │      │ type + Enter / click send
  │      ▼
  ├──► Stage 3: Full conversation panel (380×400px, glassmorphism)
  │      │ click outside / Escape
  │      ▼
  │   Collapse back to launcher
  │
  └──► Exit-intent overlay (only if never interacted)
         │ mouse moves to top edge
         ▼
      Full-screen modal with chatbot

Widget JS ──POST /wp-json/malachy/v1/chat──► WordPress REST API (PHP)
                                              │
                                              ├── Static Q&A cache (12 patterns)
                                              │     ↓ if no match
                                              ├── Fetch portfolio context from CPTs
                                              ├── Build messages array for LLM
                                              ├── POST https://opencode.ai/zen/go/v1/chat/completions
                                              │     Model: mimo-v2.5
                                              │     Bearer: OPENCODE_API_KEY
                                              ├── Return { reply: string }
                                              └── If lead detected → POST /wp-json/malachy/v1/chat/lead
                                                     └── wp_mail() to site owner
```

1. Bot detects hiring/contact intent
2. Shows inline form with Name + Email
3. Visitor fills and submits
4. PHP sends `wp_mail()` to site owner
5. Success message shown in chat
